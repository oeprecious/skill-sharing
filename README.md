# skill-sharing

A vanilla JavaScript skill-sharing platform built to practice DOM manipulation and event handling.

**Live Demo:** https://oeprecious.github.io/skill-sharing/

## About
Skill-sharing is a simple platform where users can submit talks, view others' talks, and leave comments. Built with no frameworks. Just HTML, CSS and Vanilla JS.

## Features
- Submit a Talk (Title + Summary)
- View Talks with Author Name
- Delete Talk
- Add Comments
- Enter Your Name to personalize
- Dynamic DOM updates without page reload

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

## How to Run
1. Clone: `git clone https://github.com/oeprecious/skill-sharing.git`
2. Open `index.html` in your browser

## What I Learned
- DOM manipulation
- Form handling & event delegation
- Rendering dynamic lists and comments
- Managing state with plain JS
